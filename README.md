# simplycal-legal

Pages légales de **SimplyCal** : politique de confidentialité, conditions
d'utilisation et suppression de compte.

Elles vivent dans un dépôt **public et séparé** parce que Google Play exige
qu'elles soient accessibles à quiconque, sans installer l'app — le code de
l'app, lui, reste privé.

Publiées par GitHub Pages sur
<https://linguabook-dev.github.io/simplycal-legal/>.

## À tenir à jour

Ces pages décrivent ce que l'app fait vraiment. Une politique qui décrit mal le
traitement des données est un motif de retrait, pas un détail de forme.

À relire à chaque fois que l'app se met à envoyer, stocker ou recevoir quelque
chose de nouveau — et à redater en haut de page.
